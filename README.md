# revenue-by-phone-analysis
Использует список номеров телефонов и дат в excel файле в качестве базы для анализа. По результатам скрипт покажет выручку, прибыль и продажи по списку номеров за указанный период. Кроме того, разобьёт продажи по направлениям бизнеса и точкам. Поддерживает пакетную обработку файлов (для каждого номера свои фильтры дат).
# задачи, которые решает скрипт
- посчитать выручку по точкам или направлениям бизнеса (по списку клиентов);
- анализировать результаты рассылок, акций и т.д.;
- считать выручку по клиенту (клиентам) за период;
- проверить покупал ли клиент в СТО или магазине.

# Revenue by Phone Analysis
Python script for calculating revenue based on a list of customer phone numbers.

## 📊 Features
- Match phone numbers with transaction data
- Calculate total revenue per customer
- Aggregate financial results
- Simple and extendable logic

## 📘 Description
This project analyzes customer revenue based on phone numbers.  
It processes input data and calculates how much revenue each customer has generated.
