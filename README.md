# revenue-by-phone-analysis
Использует список номеров телефонов и дат в excel файле в качестве базы для анализа. По результатам скрипт покажет выручку, прибыль и продажи по списку номеров за указанный период. Кроме того, разобьёт продажи по направлениям бизнеса и точкам. Поддерживает пакетную обработку файлов (для каждого номера свои фильтры дат).
